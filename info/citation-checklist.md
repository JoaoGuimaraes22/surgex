# Citation Building Checklist

## NAP (use exactly this everywhere)

```
Name:     SurgeX
Address:  Lisboa, Portugal
Phone:    +351 915 109 181
Website:  https://surgex.pt
Email:    contact@surgex.pt
Category: Digital Agency / Web Development / AI Solutions
```

## Directories

### High Priority (PT authority sites)

- [ ] **Páginas Amarelas** — https://www.pai.pt/registar-empresa
  - Category: "Agências Digitais" or "Desenvolvimento Web"
  - Free basic listing

- [ ] **Racius** — https://www.racius.com
  - Company registry aggregator, may auto-list if NIF is registered
  - Check if SurgeX already appears, claim if so

- [ ] **Infoempresas** — https://www.infoempresas.com.pt
  - Similar to Racius, auto-indexes PT companies
  - Claim/update if listing exists

- [ ] **Google Business Profile** — https://business.google.com
  - THE most important one. Create if not done yet
  - Add services, photos (portfolio screenshots), business hours
  - Post updates weekly (blog post links work great)
  - Collect reviews from clients

### Medium Priority (general directories)

- [ ] **Cylex Portugal** — https://www.cylex.pt/adicionar-empresa
  - Free listing with description, hours, photos
  - Category: "Desenvolvimento de Software" or "Marketing Digital"

- [ ] **Hotfrog** — https://www.hotfrog.pt
  - Free business profile
  - Add services, description, contact info

- [ ] **eInforma** — https://www.einforma.pt
  - B2B directory, auto-indexes from commercial registry
  - Claim if listing exists

- [ ] **Clutch** — https://clutch.co/profile (register)
  - Tech/agency directory, international authority
  - Takes longer to set up but high domain authority backlink
  - Add portfolio, client reviews

### Lower Priority (supplementary)

- [ ] **LinkedIn Company Page** — https://linkedin.com/company/setup
  - Not a directory per se, but Google indexes it
  - Add website link, services, description
  - Post blog content regularly

- [ ] **Crunchbase** — https://www.crunchbase.com/add-new
  - Tech company directory
  - Free basic profile

- [ ] **Yelp Portugal** — https://biz.yelp.pt
  - Less used in PT but Google still indexes it

## Tips

- Do all of these in ONE sitting — consistency is easier when you do it all at once
- Copy/paste the NAP block above, don't retype (avoids typos)
- Use the same logo everywhere (the SurgeX logo from the site)
- For descriptions, use: "Agência digital em Lisboa especializada em websites, automações e soluções de IA para negócios locais. 60+ projetos entregues."
- Save login credentials somewhere — you'll need them if you ever update the listing
- After completing, Google "SurgeX Lisboa" in ~2-4 weeks to see citations appearing
